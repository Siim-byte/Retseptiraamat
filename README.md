# Retseptiraamat

C# rakendus retseptide salvestamiseks, otsimiseks ja haldamiseks. Projekti eesmärk on praktiseerida objektorienteeritud programmeerimist (OOP) ja andmete struktureerimist.

##  Peamised funktsioonid
* Uute retseptide lisamine koos koostisosade ja valmistamisjuhistega.
* Retseptide otsimine nime või koostisosa järgi.
* Olemasolevate retseptide muutmine ja kustutamine.

##  Kasutatud tehnoloogiad
* **Keel:** C# (.NET)
* **Andmete salvestamine:** *(täpsusta: nt SQL andmebaas / JSON / tekstifailid)*

##  Käivitamine
1. Klooni repositoorium:
   ```bash
   git clone https://github.com
   ```
2. Ava projekt Visual Studios ja käivita rakendus (`F5`).
